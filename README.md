# Campus Student Management System

A beginner-friendly MCA mini project built with HTML5, CSS3, Bootstrap 5, and vanilla JavaScript.

## Features
- Responsive layout and Bootstrap navigation
- Student statistics cards
- Add and edit student records with a Bootstrap modal
- Required-field and duplicate roll/email validation
- Search and course filtering
- Delete confirmation dialog
- Browser `localStorage` persistence
- Responsive student table, toast notifications, hover effects, CSS animation
- Semantic HTML5 elements and contact `mailto:` link

## Run it
1. Extract the project folder.
2. Open `index.html` in a browser, or open the folder in Visual Studio Code and run it with Live Server.
3. Keep an internet connection for Bootstrap and Google Fonts CDN resources.

## Files
- `index.html` — page structure and Bootstrap components
- `style.css` — custom styling, transitions, animation, responsive adjustments
- `script.js` — add/edit/delete, validation, search/filter, localStorage

## Important limitations
This is a front-end learning demo. Records are saved only in the current browser on the current device. It has no real login, shared database, or server-side security. Do not use real or sensitive student information.

## Suggested practical viva topics
- Semantic HTML: `header`, `nav`, `main`, `section`, `article`, `footer`
- Bootstrap: containers, grid, responsive navbar, buttons, modal, toast, table, form controls
- CSS: external stylesheet, transitions, `:hover`, `:focus`, `@keyframes`, media queries
- JavaScript: DOM selection, event listeners, form validation, `confirm()`, template rendering
- Browser storage: `localStorage`, JSON serialization and parsing
